# 病院のサイバー問診アシスタント

その「はい」、本当に大丈夫？ ― サイバーセキュリティ対策チェックリストを、専門家の目でもう一度

Built with Claude: Japan 2026 の提出作品です（テーマ2「本来、誰にでも届くべきものを。」）。

中小病院でチェックリストを担当する事務職員のための Web アプリです。「はい」の裏に隠れた、ランサムウェアで病院が止まる穴を問診で見つけます。さらに、保守ベンダーとのやりとりを通訳して、その穴を埋めていきます。

- 公開 URL：https://cyber-monshin.vercel.app/ （検証中は、合言葉で API を保護しています）
- 仕様：[SPEC.md](SPEC.md)
- 問診の設計：[docs/agent-design.md](docs/agent-design.md)
- 開発の記録：[DEVLOG.md](DEVLOG.md)
- 評価の台帳：[eval/history.jsonl](eval/history.jsonl)

> このアプリは点検を助けるもので、対策の準拠を保証したり、法的な判断をしたりしません。厚生労働省の公式ツールではありません。サンプルの黒戸（くろうど）記念病院と黒戸町は架空です。

## 使い方

今回の対象は、重点項目のうち「バックアップと復旧」（チェックリスト 3-②）です。

1. **読み込む**：「サンプルで試す」を押すか、去年のチェックリスト（医療機関用の Excel）を読み込みます。Excel はブラウザの中で読み、送るのは 3-② の回答だけです。読み取れないときは「要確認」になり、画面で選び直します
2. **問診する**：専門用語を使わない質問に答えます。質問ごとに「なぜこの質問？」が出ます
3. **判定が変わる**：Claude が回答から観点の状態を読み取り、コードが判定を計算します。判定カードは根拠つきで変わります
4. **ベンダーへ聞く**：穴があれば、そのまま送れる質問文ができます
5. **結果を保存する**：止まる穴トップ3と、費用別の次の一手が出ます。結果は手元のファイルに保存でき、説明用の1枚も印刷できます
6. **返事を読み解く**：後日、保存したファイルを読み込み、ベンダーの返事を貼り付けます。要件ごとに、答えている点と答えていない点を、返事の原文つきで示します

## しくみ

| 担当 | 決めること |
| --- | --- |
| Claude | 次に何を聞くか、回答から観点の状態をどう読むか、ベンダーの返事が要件に答えているか |
| コード | 判定、根拠、止まる穴の順位、次の一手。どれも固定データから計算するので、同じ状態なら必ず同じ結果になる |
| 人（事務職員） | 質問への回答、ベンダーへの送信 |

- **ツール利用：** Claude は Messages API のツール利用で問診を進めます。渡すツールは記録と参照だけです
- **入力の検証：** 回答に基づかない報告は、コードが受け付けません
- **引用の確認：** ベンダーの返事からの引用が返事に実在するかを、コードで確かめます。実在しない引用は「回答なし」として扱います
- **回答の扱い：** 病院の回答はサーバーに保存せず、ログにも本文を残しません。会話の履歴はブラウザが持ちます。偽造を防ぐため、サーバーが改ざん検知の署名を付けます

## 評価

`npm run eval` で、架空の6ケースを各3回、台本の回答で動かします。結果は [eval/history.jsonl](eval/history.jsonl) に追記します。最新の結果（2026-11-03）は次のとおりです。

| 指標 | 結果 |
| --- | --- |
| 仕込んだ穴の検出率 | 100% |
| 誤検出 | 0件 |
| 判定の一致 | 100%（18回） |
| 偽の指示を含む返事 | 3回とも従わなかった |
| 費用 | 1回あたり約 $0.10〜$0.20 |

ケースが少なく、回答も台本どおりです。そのため、実際の回答の揺れまでは測れていません。経緯は [DEVLOG.md](DEVLOG.md) にあります。

## Claude Code の活用

| 使ったもの | 目的と、実際に役立ったこと |
| --- | --- |
| [CLAUDE.md](CLAUDE.md) | 設計の原則と禁止事項を共有した。「判定はコードが計算する」「回答の本文をログに残さない」など |
| フック（[.claude/settings.json](.claude/settings.json)） | コミットの前に、API キーや公開しない名前が入っていないかを[スクリプト](scripts/check-public-safety.mjs)で止める。作業の終わりには型チェックを自動で走らせる。`.env` は読まない設定にした |
| サブエージェント | [reviewer](.claude/agents/reviewer.md) が、書いた本人とは別の文脈で実装を仕様と照合した。失敗時に画面が戻らない不具合などを見つけた。厚生労働省の資料から根拠の箇所を探す調査も任せ、引用は PDF の原文と照合した |
| 評価 | 評価で、同じ観点の要件を後の結果で上書きする不具合を見つけた。甘くならない側にまとめるよう直した |
| ブラウザでの確認 | 画面を操作して、問診、返事の検証、保存と再開を実際に通した |

## 開発

```bash
npm install
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm test` | 判定、引用、署名、保存ファイル、Excel の読み取りなどの自動テスト |
| `npm run typecheck` / `npm run lint` / `npm run build` | 型チェック、lint、ビルド |
| `npm run check:safety` | 公開リポジトリに入れてはいけないものの確認 |
| `npm run eval -- --note "変更内容"` | 評価。費用がかかる |

### 環境変数

| 名前 | 内容 |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude API のキー。サーバーだけで使う |
| `ACCESS_CODE` | 検証中の合言葉。本番で未設定なら API はすべて止まる |
| `SESSION_SECRET` | 履歴の署名に使う32文字以上の文字列。`openssl rand -hex 32` で作る。本番で未設定なら API はすべて止まる |

ローカルでは `.env` に書きます。`ACCESS_CODE` がなければ、合言葉なしで動きます。
